# Get Started with Spark Core Foundry Local

Please install this package as the extra for `spark-core`:

```bash
pip install spark-core-foundry-local --pre
```

and see the [README](https://github.com/microsoft/spark-core/tree/main/python/README.md) for more information.

## Foundry Local Sample

See the [Foundry Local provider sample](../../samples/02-agents/providers/foundry/foundry_local_agent.py) for a runnable example.
