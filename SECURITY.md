# Security Policy

## Reporting Security Issues

We take the security of **Spark Core** seriously.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report any security vulnerabilities directly to the maintainers via [GitHub Security Advisories](https://github.com/arjun-chaudhry/Spark-Core/security/advisories) or contact the project maintainer **arjun-choudhary**.

Please include as much of the following information as possible to help us triage the issue quickly:
- Type of issue (e.g., buffer overflow, code injection, credentials leak, etc.)
- Affected component or source file path
- Step-by-step instructions or proof-of-concept to reproduce the issue
- Potential impact of the issue

We appreciate your effort in responsibly disclosing security vulnerabilities.
